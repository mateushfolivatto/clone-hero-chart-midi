## Baixar e adicionar sem repetir

**Ajuste `$biblioteca` para a pasta Songs realmente configurada no seu Clone Hero.**
O bloco baixa só The Strokes em Downloads, compara com sua biblioteca instalada
e gera `Novas-musicas.zip` com as músicas ausentes. O caminho padrão usa
Documentos do Windows, inclusive com redirecionamento. Se o jogo escaneia várias
raízes, inclua todas as músicas instaladas na comparação.

Requer Windows 10/11 x64 e Python 3.11+. Reserve **3 GB livres** para fontes,
conversão, pastas, ZIPs e cópia instalada. Não exige uv, Mido, FFmpeg, login,
WSL ou permissão administrativa. Os leitores portáteis têm versão e SHA256 fixos;
o instalador do 7-Zip é lido como arquivo compactado, sem executá-lo.

Espere outro baixador terminar ou encerre-o com Ctrl+C. Cole no PowerShell:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $base = 'https://raw.githubusercontent.com/mateushfolivatto/clone-hero-chart-midi/main/src/drumforge/library'
    $pasta = Join-Path $env:USERPROFILE 'Downloads\TheStrokes'
    $biblioteca = Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'Clone Hero\Songs'
    $baixador = Join-Path $pasta 'Baixador'
    New-Item -ItemType Directory -Path $baixador -Force | Out-Null
    foreach ($arquivo in @('recover_pilot.py', 'onyx_recovery.py', 'sevenzip.py', 'mega_recovery.py', 'collection_index.json')) {
        Invoke-WebRequest -Uri "$base/$arquivo" -OutFile (Join-Path $baixador $arquivo) -UseBasicParsing
    }
    $indice = Get-Content -LiteralPath (Join-Path $baixador 'collection_index.json') -Raw | ConvertFrom-Json
    $lotes = @($indice.batches | Where-Object { $_.theme -eq 'strokes' })
    if ($lotes.Count -eq 0) { throw 'Nenhum lote The Strokes encontrado. Atualize e tente novamente.' }
    foreach ($lote in $lotes) {
        if ($lote.manifest -notmatch '^collection_[0-9]{2,}\.json$') { throw 'Nome de receita invalido' }
        Invoke-WebRequest -Uri "$base/$($lote.manifest)" -OutFile (Join-Path $baixador $lote.manifest) -UseBasicParsing
    }
    foreach ($arquivo in @('additions.py', 'complement.py', 'local_library.py')) {
        Invoke-WebRequest -Uri "$base/$arquivo" -OutFile (Join-Path $baixador $arquivo) -UseBasicParsing
        $esperado = $indice.addition_helpers.PSObject.Properties[$arquivo].Value
        if ($esperado -notmatch '^[a-f0-9]{64}$' -or (Get-FileHash -Algorithm SHA256 -LiteralPath (Join-Path $baixador $arquivo)).Hash -ne $esperado) {
            throw 'Comparador diferente do indice. Execute novamente para atualizar.'
        }
    }
    $downloadsPendentes = $false
    foreach ($lote in $lotes) {
        py -3 (Join-Path $baixador 'recover_pilot.py') --restante --lote $lote.number --destino $pasta
        if ($LASTEXITCODE -eq 130) { throw 'Interrompido. Execute novamente para retomar.' }
        if ($LASTEXITCODE -ne 0) { $downloadsPendentes = $true }
    }
    $saida = Join-Path $pasta ('Para-adicionar-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
    py -3 (Join-Path $baixador 'additions.py') --candidatas (Join-Path $pasta 'Songs') --biblioteca $biblioteca --destino $saida
    if ($LASTEXITCODE -ne 0) { throw 'Comparacao pendente. Confira o caminho de Songs e a mensagem acima.' }
    if ($downloadsPendentes) { Write-Warning 'Ha downloads pendentes. Execute novamente para retomar e comparar as novas pastas prontas.' }
    Invoke-Item $saida
}
```

Na pasta aberta, confira `comparacao.csv`. **Extraia a pasta `Novas-musicas` do
ZIP diretamente em Songs uma única vez** e execute **Scan Songs**. Escolha
Pro Drums / Expert no lote 41; no lote 42, escolha **Drums / Expert**.
As duas faixas de bateria comum são “Ode to the Mets” e “12:51”.
Não copie também as pastas baixadas: elas são as mesmas músicas usadas na comparação.
Mantenha Downloads e backups fora de todas as raízes escaneadas.

Pastas renomeadas continuam reconhecíveis. Músicas já instaladas e cópias repetidas
ficam fora do ZIP; versões incertas ou o mesmo chart com áudio diferente ficam
em `revisar`. O comparador preserva os arquivos de entrada. Veja
[ADICIONAR-SEM-REPETIR.md](ADICIONAR-SEM-REPETIR.md).

Repita o bloco para retomar pendências. As receitas, fontes e arquivos existentes
são conferidos por hash; edições locais não são substituídas. Falhas aparecem em
`*-falhas.json`; as outras músicas/lotes continuam. A comparação usa somente
pastas prontas. Compare novamente depois que os downloads terminarem.

## Pendências e validação

A busca consultou 85 pacotes de bateria no RhythmVerse e 26 no Encore; alternativas
do mesmo título não viram novas músicas. Foram considerados 25 títulos para
fechar esta seleção de 20. “Bad Decisions” e “Call It Fate, Call It Karma” não
tiveram correspondência conservadora de bateria nesses catálogos. “Machu Picchu”
ficou com as fontes indisponíveis. Ize of the World e Under Control foram
conferidas como reservas e ficaram fora deste lote.
O [relatório da seleção](reports/the-strokes.csv) registra cada resultado.
“Não encontrado” descreve esta busca, sem comprovar inexistência global.

As receitas do piloto e dos lotes 02–40, helpers e correções do Onyx foram
preservados. Windows CLI continua sem RTS, com logs em Logs/Onyx, feedback a cada
15 segundos e limites de espera de 180/900 segundos. SNG, 7-Zip, retomada e
comparador local continuam usando os mesmos leitores. A cobertura das 744
entradas do Qobuz e os experimentos/perfil de áudio permanecem intactos.

Os arquivos foram inspecionados na nuvem Linux: bateria Expert de quatro pistas,
bumbo, evidência Pro quando presente, áudio decodificado e hashes/ZIPs. Não houve
transcrição, alteração de batidas, áudio de streaming ou instalação de modelos.
Drums comuns não foram forçados a Pro. Execução nativa no Windows, sincronismo
percebido e jogabilidade aguardam teste individual; `game_verified` continua falso.
Veja [a verificação técnica](../docs/library-strokes-verification.md).
